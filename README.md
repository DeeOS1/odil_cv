# Портфолио Одил Бегзода — Next.js + Vercel

Это рабочая структура **Next.js App Router**, подготовленная из нашего интерактивного HTML-портфолио. Основная страница находится в `app/page.jsx`, глобальные стили — в `app/globals.css`, интерактивность — в `public/portfolio.js`. Используются React, Next.js, CSS и JavaScript.

## Быстрый запуск на компьютере

Понадобится Node.js **20.9 или новее** (предпочтительно актуальная LTS) и npm.

```bash
npm install
npm run dev
```

Открой http://localhost:3000

Для проверки production-сборки:

```bash
npm run build
npm run start
```

## Публикация через Vercel (рекомендуемый вариант)

1. Распакуй ZIP, создай новый репозиторий на GitHub и загрузи в него **содержимое** папки `Odil_NextJS_Vercel` (в корне репозитория должен находиться `package.json`).
2. Открой https://vercel.com/new и импортируй этот репозиторий.
3. Vercel определит фреймворк **Next.js**. Оставь `Root Directory: ./`, `Build Command: next build` (по умолчанию) и нажми **Deploy**.
4. После сборки появится адрес `https://...vercel.app` — это ссылка на онлайн-портфолио, которую впоследствии можно включить в QR-код Word-CV.

Можно также установить CLI и выполнить `npx vercel` в каталоге проекта, затем `npx vercel --prod`.

## Структура

```
app/
  layout.jsx             # Заголовки страницы, иконки вкладки, глобальная оболочка
  page.jsx               # Все разделы сайта в JSX
  components/
    ResumeDownloads.jsx  # Варианты резюме и ссылки для скачивания
  globals.css            # Оригинальное оформление и адаптивность
  favicon.ico            # Иконка вкладки
  apple-icon.png         # Иконка для смартфона
public/
  portfolio.js           # Интерактивность: тема, фильтры, модальные окна, орбита
  assets/                # Логотип и изображения
  docs/                  # PDF и DOCX для скачивания
package.json
next.config.mjs
jsconfig.json
```

## Что сохранилось

- Тёмная и светлая темы, плавные анимации и адаптивность.
- Четыре интерактивные иконки на главном экране: переключение по наведению и фильтрация проектов по нажатию.
- Восемь карточек проектов с подробностями во всплывающих окнах, включая ИИ-поддержку на Openfire и Zammad.
- Разделы об опыте, навыках, образовании, контактах.
- Блок выбора резюме: мини-CV (PDF и Word), полное CV (Word) и CV с подробными проектами (Word). Файлы лежат в `public/docs/`, ссылки заданы в `app/components/ResumeDownloads.jsx`.
- Логотип в шапке и favicon.

## Резюме для скачивания

Кнопки «Выбрать резюме» и «Все варианты резюме» ведут к блоку `#resume`.
Варианты и имена скачиваемых файлов заданы в `app/components/ResumeDownloads.jsx`:

| Вариант | Формат | Файл в `public/docs/` |
| --- | --- | --- |
| Мини-CV | PDF | `odil-mini-cv.pdf` |
| Мини-CV | Word | `odil-mini-cv.docx` |
| Полное CV | Word | `odil-full-cv.docx` |
| CV с проектами | Word | `odil-projects-cv.docx` |

Файлы с латинскими именами — копии исходных резюме с русскими именами.
При обновлении резюме заменяйте соответствующий файл из таблицы.

## Личная информация

В профиль и резюме добавлены телефон, Telegram, электронная почта и дата рождения. Сайт и резюме оформлены без фотографии. Контактный блок сайта находится в `app/components/ProfileContacts.jsx`.

При разработке можно изменять JSX в `app/page.jsx` и стили в `app/globals.css`. Существующий JS работает после загрузки React-страницы и оставлен отдельно, чтобы сохранить все текущие эффекты. При последующем рефакторинге его можно заменить React-хуками и компонентами.
